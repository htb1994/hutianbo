# 洋葱学园社群运营自动化工作台

这个服务跑在你的 Mac 上，用飞书多维表格作为入口，自动生成社群运营资料并把结果链接回填到飞书。

## 第一版能力

第一版先做「生成、审核、回传」，不直接自动发群。

- 生成社群 SOP 云文档
- 生成每日群发内容
- 生成配套话术包
- 生成转化私聊话术
- 生成转化跟进清单
- 生成数据看板简报
- 生成表彰物料执行说明
- 自动把结果链接回填飞书任务表
- 自动在输出归档表新增一条记录

## 飞书内使用方式（给部门同事）

同事日常使用不需要打开终端，也不需要输入命令，只在飞书多维表格里操作。

### 方式一：飞书机器人生成 SOP

第一版机器人入口已经接入云端服务。同事可以在飞书里私聊机器人，或在群里 @ 机器人后发送一句完整需求。

示例：

```text
生成长沙中建仰天湖小学小学14天开学收心营SOP，8月24日开始，周末轻服务，服务转化版，产品重点同步学、提前学、同步刷题、学情报告，需要结营表彰。
```

机器人会自动完成：

1. 解析项目名称、城市、学校/校区、学段、周期、开始日期、周末规则、模板类型、产品重点。
2. 如果缺少必要字段，会在当前会话追问。
3. 信息完整后写入「项目配置」表。
4. 自动调用 SOP 生成服务。
5. 生成完成后把飞书云文档链接回复给老师。

当前支持的机器人命令：

```text
/help    查看示例
/status  查看当前补齐进度
/reset   重置当前会话
```

如果要配置飞书开放平台事件订阅，请把机器人消息事件地址填写为：

```text
https://onion-sop-automation.onrender.com/api/lark/events
```

需要订阅事件：

```text
im.message.receive_v1
```

需要开通的常用权限：

```text
im:message
im:message:send_as_bot
base:record:read
base:record:create
base:record:update
docx:document
drive:drive
```

注意：机器人创建记录时会先写成 `生成中`，然后由云端服务直接生成，避免和多维表格自动化重复触发。

### 生成完整 SOP

1. 打开飞书工作台：<https://guanghe.feishu.cn/base/NhJRb1nCLakcPEsFjSNcZ4lwnWt>
2. 进入「项目配置」表，新建一行。
3. 填写项目名称、城市、区县/校区、学段、社群周期、开始日期、模板类型、产品重点。
   - 标准填写路径里不需要问 `结束日期`。
   - 如果 `社群周期` 选择 `自定义`，只填 `运营天数`。
   - 系统会按 `开始日期 + 社群周期/运营天数 - 1天` 自动计算结束日期。
   - 只有兼容旧表单时才保留 `结束日期`，并且会自动优先读取你手动填写的值。
4. 把「生成状态」改成 `待生成`。
5. 等待后台自动生成，完成后会回填「SOP云文档链接」，状态变成 `待审核`。

如果你们更想用表单填报，优先使用「SOP生成表单（简化版）」：它已经去掉了大部分杂项字段，`运营天数`只在`社群周期=自定义`时出现，`生成状态`需要选择`待生成`才能自动触发生成。

### 智能体提问顺序建议

智能体或表单只需要按这个顺序问：

1. 项目名称
2. 城市 / 区县 / 校区
3. 学段
4. 社群周期
5. 如果社群周期是自定义，再问运营天数
6. 开始日期
7. 周末规则
8. 模板类型
9. 产品重点
10. 是否需要结营表彰

不要默认追问结束日期，除非你是在兼容旧入口。

后台生成时会自动读取：

- 「SOP模板库」：匹配最合适的 SOP 正文、素材规则、鼓励师规则和转化节点
- 「素材库」：匹配图片、视频、APP操作素材和课程价值素材
- 「话术库」：匹配开营、打卡、未打卡、课程价值、转化、异议处理话术
- 「运营数据日报 / 转化跟进表」：生成看板、跟进清单和转化建议

生成规则：只要「SOP模板库」匹配到可用模板正文，系统会按模板完整生成，保留 Day-by-Day 节点、群内话术、私聊话术、鼓励师互动、素材占位和转化节奏；不会只生成摘要框架。没有匹配到模板正文时，才使用默认兜底框架。

### 生成规则沉淀

项目级规则集中在 `src/generationRules.js`，不要把临时替换散落在模板或生成器里。当前已沉淀：

- 活动名称规则：根据项目名称/模板类型识别「暑假加油站」或「开学收心营」。
- 日期规则：`结束日期`可选；未填写时，系统根据`开始日期`和`社群周期/运营天数`自动推算。
- 开学收心营规则：模板里的“暑假加油站、暑假作业打卡、暑促、暑假后半段、暑假天气热、2026暑假社群运营”等表达会统一改成开学收心营/开学季/开学前后表达。
- 学段收窄规则：项目只选「初中」时，模板里的“小学、初中、高中”会收窄为“初中”，小学/高中专属话术会改成初中表达。
- 结营表彰规则：勾选结营表彰只会追加表彰模块，不会让完整 SOP 错选为结营表彰单页模板。
- 标题一致规则：模板标题、模板说明、素材配置规则、鼓励师话术规则、转化节点和正文一起本地化，不只改正文。
- 权限规则：新生成的飞书 Docx 默认设置为 `tenant_editable`，即组织内获得链接的人可编辑。

后续如果新增「寒假营」「中考冲刺营」「高考规划营」等活动，优先在 `src/generationRules.js` 里新增活动规则和词组映射，再补测试。

### 生成话术、群发内容、看板和跟进清单

1. 进入「任务表」。
2. 新建一行，选择任务类型。
3. 填写学校、活动名称、年级/学段、学生名单或补充要求。
4. 把「生成状态」改成 `待生成`。
5. 生成完成后查看「结果链接」。

### 接入飞书智能体 / Aily 的方式

第一版推荐让智能体只做“填表触发”，不要让同事面对命令。

智能体需要完成三件事：

1. 询问运营老师：城市、学校、学段、周期、开始日期、产品重点、是否结营表彰；自定义周期时再询问运营天数。
2. 写入「项目配置」或「任务表」，并把「生成状态」设置为 `待生成`。
3. 引导运营老师回到飞书表格查看自动回填的云文档链接。

这样同事在飞书里对智能体说“帮我生成衡阳成章实验中学14天暑假加油站SOP”，智能体负责收集信息和写表，后台服务负责读取模板库和数据生成文档。

## 飞书自动化 Webhook 方案（方案一）

这一版用于把“本地终端常驻轮询”升级成“飞书表单/多维表格提交后自动调用云端服务”。同事仍然只填飞书，管理员把服务部署到云端后，电脑不需要一直开着。

### 云端接口

部署服务后，需要对外暴露：

- 健康检查：`GET /health`
- 生成接口：`POST /api/generate`

云端服务还会默认启用兜底轮询：即使飞书自动化没有识别“新建记录时生成状态已是待生成”的场景，服务也会定时扫描项目配置和任务表里的 `待生成` 记录并自动生成。需要关闭时设置环境变量 `SOP_ENABLE_POLLING=false`。

本地测试时可先运行：

```bash
npm run webhook
```

默认本地地址：

```text
http://localhost:8787
```

云端部署后，把 `http://localhost:8787` 换成云服务域名，例如：

```text
https://your-sop-service.example.com
```

### 飞书自动化配置

在「项目配置」表里配置自动化：

1. 触发条件：当记录被创建或更新
2. 条件：`生成状态` 等于 `待生成`
3. 动作：发送 HTTP 请求 / Webhook
4. 请求方法：`POST`
5. 请求地址：`https://你的云服务域名/api/generate`
6. 请求头：

```text
content-type: application/json
x-sop-secret: 你的Webhook密钥
```

7. 请求体：

```json
{
  "type": "project",
  "recordId": "{{记录ID}}"
}
```

如果是「任务表」触发，使用：

```json
{
  "type": "task",
  "recordId": "{{记录ID}}"
}
```

不同飞书自动化界面里“记录ID”的变量名称可能显示为“记录 ID / Record ID / 当前记录 ID”，选择当前触发记录的 record id 即可。

### Webhook 密钥

部署时建议用环境变量配置密钥：

```bash
SOP_WEBHOOK_SECRET="一串只有你知道的密钥"
```

飞书自动化请求头里的 `x-sop-secret` 必须和它一致，否则接口会返回 401。

### 本地测试请求

```bash
curl http://localhost:8787/health
```

```bash
curl -X POST http://localhost:8787/api/generate \
  -H "content-type: application/json" \
  -d '{"type":"project","recordId":"recxxxx"}'
```

## Render 免费版部署

Render 可以先用免费 Web Service 跑通测试。免费版空闲后会休眠，第一次被飞书自动化调用时可能会慢一些；如果后续经常超时，再升级付费小实例。

### 1. 准备代码仓库

Render 最方便的方式是从 GitHub 仓库部署。把本项目里的 `sop-automation` 目录推到 GitHub 后，在 Render 里选择该仓库。

### 2. 创建 Web Service

在 Render 控制台选择：

```text
New + -> Web Service
```

配置建议：

| 项 | 值 |
| --- | --- |
| Root Directory | `sop-automation` |
| Runtime | `Node` |
| Build Command | `npm install` |
| Start Command | `npm run render:start` |
| Instance Type | `Free` |
| Health Check Path | `/health` |

项目里已经提供 `render.yaml`，如果 Render 识别 Blueprint，也可以直接按 Blueprint 创建。

### 3. 配置环境变量

在 Render 的 Environment 里添加：

| 环境变量 | 示例 | 说明 |
| --- | --- | --- |
| `LARK_IDENTITY` | `bot` | 云端建议用 bot 身份 |
| `LARK_CLI_PATH` | `./node_modules/.bin/lark-cli` | Render 安装后的 CLI 路径 |
| `LARK_BRAND` | `feishu` | 使用飞书 |
| `LARK_APP_ID` | `cli_xxx` | 飞书应用 App ID |
| `LARK_APP_SECRET` | 不写入文档 | 飞书应用 App Secret |
| `SOP_WEBHOOK_SECRET` | 自定义一串密钥 | 飞书自动化请求时要带同一密钥 |
| `FEISHU_BASE_TOKEN` | `NhJR...` | 多维表格 App Token |
| `SOP_TABLE_PROJECTS` | `tbl...` | 项目配置表 ID |
| `SOP_TABLE_TEMPLATES` | `tbl...` | SOP模板库表 ID |
| `SOP_TABLE_MATERIALS` | `tbl...` | 素材库表 ID |
| `SOP_TABLE_OUTPUTS` | `tbl...` | 输出归档表 ID |
| `SOP_TABLE_TASKS` | `tbl...` | 任务表 ID |
| `SOP_TABLE_SCRIPTS` | `tbl...` | 话术库表 ID |
| `SOP_TABLE_FOLLOWUPS` | `tbl...` | 转化跟进表 ID |
| `SOP_TABLE_DASHBOARD` | `tbl...` | 运营数据日报表 ID |
| `SOP_DOC_LINK_SHARE_ENTITY` | `tenant_editable` | 新生成 Docx 的链接权限；默认组织内链接可编辑，也可设为 `tenant_readable` 或 `skip` |

### 4. 飞书权限注意

Render 上推荐 `bot` 身份，所以需要确认：

- 飞书应用已开通 Base 记录读写权限
- 飞书应用已开通 Docx 文档创建/写入权限
- 这个 bot 能访问当前多维表格和生成文档所在空间

如果 bot 访问不了 Base，需要把应用/bot 添加到对应多维表格或知识库权限中，或者继续使用本地 user 模式。

### 5. 部署成功后的飞书自动化地址

Render 会给一个 HTTPS 域名，例如：

```text
https://onion-sop-automation.onrender.com
```

飞书自动化 Webhook 请求地址填写：

```text
https://onion-sop-automation.onrender.com/api/generate
```

请求头：

```text
content-type: application/json
x-sop-secret: 你在 Render 设置的 SOP_WEBHOOK_SECRET
```

请求体：

```json
{
  "type": "project",
  "recordId": "{{记录ID}}"
}
```

## 触发方式

### 生成 SOP

在「项目配置」表里新增或修改一行，把 `生成状态` 改成 `待生成`。

服务会自动：

- 把状态改成 `生成中`
- 读取项目配置
- 生成 SOP 云文档
- 自动匹配本地素材
- 回填 `SOP云文档链接`
- 把状态改成 `待审核`
- 在「输出归档表」新增输出记录

### 生成话术/看板/跟进清单

在「任务表」新增一行，把 `生成状态` 改成 `待生成`。

服务会自动：

- 把状态改成 `生成中`
- 根据 `任务类型` 生成飞书云文档
- 回填 `结果链接`
- 把状态改成 `待审核`
- 在「输出归档表」新增输出记录

## 当前边界

- 第一版不自动发群，只生成内容并回填链接。
- 海报/PPT 仍使用本地红金模板脚本生成，任务表第一版先生成表彰执行说明。
- 数据看板第一版先输出飞书云文档简报，后续再升级飞书仪表盘。
